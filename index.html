MSU TSU Pairing

This tool links an animal's ear tag (or other ID) to its Allflex TSU barcode. This uses your mobile device and its camera to type in an ID and scan the associated TSU barcode. The output is a .csv file that is downloaded, and can be shared, so tissue samples can be matched back to the correct animal for accurate genotyping.
