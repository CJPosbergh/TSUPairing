MSU TSU Pairing

This tool links an animal's ear tag (or other ID) to its Allflex TSU barcode. This uses your mobile device and its camera to type in an ID and scan the associated TSU barcode. The output is a .csv file that is downloaded, and can be shared, so tissue samples can be matched back to the correct animal for accurate genotyping.

New session

Each session saves to its own CSV file. Name it after the flock, group, or date — or keep the default.

When finished, this will fill the Sample Barcode and Animal ID columns of the "New Animals Being Genotyped" sheet in the NSIP submission workbook (instead of a plain CSV). You'll still need to add NSIP ID, sex, year of birth, animal type, test name, and billing info before emailing it to genomics@nsip.org and info@nsip.org.

⚠ This downloads a separate backup CSV file each time (e.g. every 5 records) as extra insurance during the session. Only the final file from "Save & finish" is the complete one — earlier backups can be deleted afterward.
